Overview

This project focuses on analyzing HR data to uncover insights about employee attrition, job satisfaction, and performance.
It uses Power BI, Excel, Tableau, and SQL to visualize patterns and support data-driven HR decisions.

Objectives

Explore and clean HR data using Excel and SQL

Identify key factors influencing employee attrition

Build dashboards in Power BI and Tableau for HR insights

Present actionable recommendations to improve retention

Conclusion

This HR Analytics project highlights how data visualization and SQL-driven insights can empower HR teams to make informed decisions.
By addressing key attrition drivers, companies can enhance employee engagement and reduce turnover.
